# עיצוב מחדש v2: "מסיבה של חלונות" (נפתח 12.10.2026, הנחיית עידו)

מבנה לפי `docs/CLAUDE-CODE-WORKFLOW.md`. פרויקט גדול, רב־שלבי, ללילה ולימים הבאים.

## הנחיית עידו (מילה במילה, בתמצית)
1. באתר עצמו מציעים **רק עיצובים מלאים**. כפתורים, סרגלים וכל הרכיבים הבודדים עוברים למקום אחר.
2. אתרי ההדגמה צריכים להיות **מעניינים ומושכים את העין**: משחקי ספורט, תעופה, גיימינג משוכלל, דברים נועזים. הרבה יותר **פרועים ומסתכנים**. "אין לנו מה להפסיד. כמו שיש עכשיו יש עוד מלא ברחבי האינטרנט."
3. **הרבה יותר תזוזה, הנפשות ואנימציה.** האתר שלנו נראה כמו **הרבה חלונות, לכל חלון חיים משלו, והכול מסיבה אחת גדולה.**
4. בנוסף אתרים **רגועים וקלאסיים**, אבל גם הם בעיצוב יוצא דופן ומרשים.

## החלטות ברירת מחדל (עידו יכול לשנות)
- הרכיבים לא נמחקים: הם עוברים ל־**מעבדת רכיבים** (`/components`, `/he/components`), קישור משני בפוטר ובסרגל. כתובות `/vault/[slug]` נשארות (SEO), בלי להופיע בעמוד הבית ובמונים הראשיים.
- אתרי הדגמה: מיקס של פרוע (≈70%) ורגוע־קלאסי (≈30%).
- כל אתר מוצג בתוך מסגרת "חלון דפדפן" חיה שזזה לבד (ambient), לא תמונה סטטית.
- אין סימנים מסחריים או דמויות מוגנות. מותגים בדויים.
